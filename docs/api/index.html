🚀 Primeros Pasos

Para consumir esta API pública, debes incluir el header apikey con la llave pública anon del proyecto en cada solicitud HTTP.

a) Consulta REST simple con fetch() (JavaScript)
const SUPABASE_URL = 'https://xrxuzvvvorxukyoeqibg.supabase.co';
const SUPABASE_ANON_KEY = 'sb_publishable_5PQ8ugmExZQulip3fmD3eA_hRMLoNqH';

async function obtenerNecesidades() {
  const response = await fetch(
    `${SUPABASE_URL}/rest/v1/api_necesidades?modo=eq.OFERTA&completado=eq.false&select=id,titulo,ubicacion`,
    {
      headers: {
        'apikey': SUPABASE_ANON_KEY,
        'Authorization': `Bearer ${SUPABASE_ANON_KEY}`
      }
    }
  );
  const data = await response.json();
  console.log('Necesidades activas:', data);
}
b) Suscripción en Tiempo Real con @supabase/supabase-js
import { createClient } from '@supabase/supabase-js';

const SUPABASE_URL = 'https://xrxuzvvvorxukyoeqibg.supabase.co';
const SUPABASE_ANON_KEY = 'sb_publishable_5PQ8ugmExZQulip3fmD3eA_hRMLoNqH';

const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);

// IMPORTANTE: Realtime debe suscribirse a la tabla "necesidades" original (las vistas no soportan Realtime)
const channel = supabase
  .channel('cambios-necesidades')
  .on(
    'postgres_changes',
    { event: '*', schema: 'public', table: 'necesidades' },
    (payload) => {
      console.log('Cambio detectado en tiempo real:', payload);
    }
  )
  .subscribe();
💡 Nota sobre Realtime: Supabase Realtime requiere suscribirse directamente a la tabla base original necesidades (las vistas de PostgreSQL no soportan suscripciones Realtime directamente).
